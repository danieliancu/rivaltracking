# RivalTracking Dashboard

Local export/reconstruction of the RivalTracking dashboard created in Lovable.

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal (usually http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

This project is independent of Lovable hosting and can be committed to GitHub or developed in VS Code.
